# Day 1 - Spring Boot 簡介

## 什麼是 Spring Boot？

Spring Boot 是一個基於 Spring 框架的開源 Java 框架。它的目標是簡化 Spring 應用的初始搭建以及開發過程。

### 核心特點：
1. **內嵌伺服器**：不需要額外安裝 Tomcat 或 Jetty，可以直接打包成 JAR 檔並運行。
2. **自動配置 (Auto-Configuration)**：Spring Boot 會根據專案依賴（Starters）自動配置 Bean，大幅減少 XML 或 Java 配置代碼。
3. **Starter 依賴**：提供了一系列「開箱即用」的依賴包（例如 `spring-boot-starter-web`），簡化 Maven/Gradle 配置。
4. **無代碼生成，不需 XML 配置**：傾向於使用註解 (Annotation) 來配置。
5. **生產就緒 (Production-ready)**：內建指標監控、健康檢查 (Actuator) 等功能。

## 為什麼要學 Spring Boot？

- **開發效率高**：快速啟動專案，專注於業務邏輯。
- **社群強大**：豐富的學習資源和成熟的解決方案。
- **微服務首選**：Spring Cloud 的基礎，非常適合構建微服務架構。
