# Day 11 - Spring AOP 簡介

## 什麼是 AOP (Aspect Oriented Programming)？

**AOP (面向切面程式設計)** 是為了將「核心業務邏輯」與「共通服務」分離的一種設計思想。

### 為什麼需要 AOP？
假設你有 10 個方法，每個方法都要：
1.  記錄開始時間
2.  記錄結束時間
3.  處理權限檢查

傳統方法：在每個方法都要重複寫這些代碼。
AOP 方法：定義一個「切面 (Aspect)」，將這些共通邏輯抽離，讓 Spring 自動在方法執行前後「切入」執行。

### 核心術語 (重點理解)
*   **Aspect (切面)**：你要切入的邏輯（例如：日誌記錄）。
*   **Join Point (連接點)**：程式執行的某個點（例如：方法執行時）。
*   **Advice (通知)**：切面要執行的動作（例如：Before, After）。
*   **Pointcut (切入點)**：定義哪些方法需要被切入（例如：所有的 Controller 方法）。
