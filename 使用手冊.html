系統啟動

🚀 方式一: 使用 Gradle (推薦)

# 1. 開啟 PowerShell，進入專案目錄
cd d:/MCP/SpringBoot/SpringBootDemo

# 2. 設定 Java 環境 (如果使用 Java 21)
$env:JAVA_HOME="C:\Program Files\Java\jdk-21"

# 3. 啟動應用程式
.\gradlew bootRun

啟動成功的標誌:

Started SpringBootDemoApplication in 3.456 seconds (process running for 3.789)

🚀 方式二: 使用 IDE (IntelliJ IDEA / Eclipse)

  1. 開啟專案
  2. 找到 SpringBootDemoApplication.java
  3. 右鍵 → Run 'SpringBootDemoApplication'

🚀 方式三: 建置 JAR 檔執行

# 1. 建置專案
.\gradlew build

# 2. 執行 JAR 檔
java -jar build/libs/SpringBootDemo-0.0.1-SNAPSHOT.jar

API 使用方式

📡 API 端點總覽

方法 路徑 功能 說明
GET /api/orders 查詢所有訂單 返回訂單列表
GET /api/orders/{id} 查詢單一訂單 根據 ID 查詢
POST /api/orders 建立訂單 新增一筆訂單
PUT /api/orders/{id} 更新訂單 修改訂單資訊
DELETE /api/orders/{id} 刪除訂單 刪除指定訂單

基礎 URL: http://localhost:8080

1️⃣ 查詢所有訂單 (GET)

使用 PowerShell

Invoke-RestMethod -Uri "http://localhost:8080/api/orders"

使用 curl

3️⃣ 建立訂單 (POST)

方法 A: 使用 JSON 檔案 (推薦)

Step 1: 建立 my-order.json 檔案

{
  "customerName": "王小明",
  "productName": "MacBook Pro 14",
  "quantity": 1,
  "price": 59900
}

Step 2: 發送請求

curl.exe -X POST http://localhost:8080/api/orders `
    -H "Content-Type: application/json" `
    -d "@my-order.json"

方法 B: 使用 PowerShell 物件

$orderData = @{
    customerName = "李小華"
    productName = "iPad Air"
    quantity = 2
    price = 18900
} | ConvertTo-Json

Invoke-RestMethod -Method POST `
    -Uri "http://localhost:8080/api/orders" `
    -ContentType "application/json" `
    -Body $orderData

方法 C: 使用 curl 直接輸入 (不推薦，容易出錯)

curl.exe -X POST http://localhost:8080/api/orders `
    -H "Content-Type: application/json" `
    -d "{\"customerName\":\"張三\",\"productName\":\"AirPods Pro\",\"quantity\":1,\"price\":7490}"

回應範例

4️⃣ 更新訂單 (PUT)

使用 PowerShell

$updateData = @{
    customerName = "王小明 (已更新)"
    productName = "MacBook Pro 16"
    quantity = 1
    price = 79900
} | ConvertTo-Json

Invoke-RestMethod -Method PUT `
    -Uri "http://localhost:8080/api/orders/2" `
    -ContentType "application/json" `
    -Body $updateData

使用 curl

# 建立 update-order.json
# {
#   "customerName": "王小明 (已更新)",
#   "productName": "MacBook Pro 16",
#   "quantity": 1,
#   "price": 79900
# }

curl.exe -X PUT http://localhost:8080/api/orders/2 `
    -H "Content-Type: application/json" `
    -d "@update-order.json"

5️⃣ 刪除訂單 (DELETE)

使用 PowerShell

Invoke-RestMethod -Method DELETE -Uri "http://localhost:8080/api/orders/2"

使用 curl

curl.exe -X DELETE http://localhost:8080/api/orders/2

回應

成功刪除會返回 200 OK，沒有內容

資料庫管理

🗄️ 使用 H2 Console (Web 介面)

Step 1: 開啟 H2 Console

在瀏覽器中訪問: http://localhost:8080/h2-console

Step 2: 輸入連線資訊

JDBC URL: jdbc:h2:mem:testdb
User Name: sa
Password: password

Step 3: 點選「Connect」

Step 4: 執行 SQL 查詢

查看所有訂單:

SELECT * FROM ORDERS;

查看訂單項目:

SELECT * FROM ORDER_ITEMS;

查詢特定客戶的訂單:

SELECT * FROM ORDERS WHERE CUSTOMER_NAME = '王小明';

統計訂單數量:

SELECT STATUS, COUNT(*) as COUNT 
FROM ORDERS 
GROUP BY STATUS;

計算訂單總金額:

SELECT SUM(PRICE * QUANTITY) as TOTAL_AMOUNT 
FROM ORDERS;

實際應用場景

場景 1: 電商訂單處理流程

# 1. 客戶下單
$order = @{
    customerName = "陳大明"
    productName = "iPhone 15 Pro Max"
    quantity = 1
    price = 42900
} | ConvertTo-Json

$newOrder = Invoke-RestMethod -Method POST `
    -Uri "http://localhost:8080/api/orders" `
    -ContentType "application/json" `
    -Body $order

Write-Host "訂單已建立，訂單編號: $($newOrder.id)"

# 2. 查詢訂單狀態
$orderStatus = Invoke-RestMethod -Uri "http://localhost:8080/api/orders/$($newOrder.id)"
Write-Host "訂單狀態: $($orderStatus.status)"

# 3. 更新訂單狀態為已完成
$update = @{
    customerName = $orderStatus.customerName
    productName = $orderStatus.productName
    quantity = $orderStatus.quantity
    price = $orderStatus.price
    status = "COMPLETED"
} | ConvertTo-Json

Invoke-RestMethod -Method PUT `
    -Uri "http://localhost:8080/api/orders/$($newOrder.id)" `
    -ContentType "application/json" `
    -Body $update

Write-Host "訂單已完成!"

場景 2: 批次匯入訂單

# 建立 orders.csv 檔案:
# customerName,productName,quantity,price
# 王小明,iPhone 15,1,29900
# 李小華,MacBook Pro,1,59900
# 張三,iPad Air,2,18900

# 讀取 CSV 並建立訂單
Import-Csv orders.csv | ForEach-Object {
    $orderData = @{
        customerName = $_.customerName
        productName = $_.productName
        quantity = [int]$_.quantity
        price = [decimal]$_.price
    } | ConvertTo-Json
    
    $result = Invoke-RestMethod -Method POST `
        -Uri "http://localhost:8080/api/orders" `
        -ContentType "application/json" `
        -Body $orderData
    
    Write-Host "已建立訂單 #$($result.id) - $($result.customerName)"
}

場景 3: 訂單報表生成

# 取得所有訂單
$orders = Invoke-RestMethod -Uri "http://localhost:8080/api/orders"

# 統計分析
$totalOrders = $orders.Count
$totalRevenue = ($orders | Measure-Object -Property price -Sum).Sum
$avgOrderValue = $totalRevenue / $totalOrders

Write-Host "=== 訂單報表 ==="
Write-Host "總訂單數: $totalOrders"
Write-Host "總營收: $$totalRevenue"
Write-Host "平均訂單金額: $$([math]::Round($avgOrderValue, 2))"

# 依狀態分組
$orders | Group-Object -Property status | ForEach-Object {
    Write-Host "$($_.Name): $($_.Count) 筆"
}

故障排除

❌ 問題 1: 無法連線到 localhost:8080

檢查步驟:

# 1. 確認應用程式是否正在運行
Get-Process | Where-Object {$_.ProcessName -like "*java*"}

# 2. 檢查 8080 連接埠是否被佔用
Get-NetTCPConnection -LocalPort 8080

# 3. 查看應用程式日誌
# 在執行 gradlew bootRun 的視窗中查看錯誤訊息

解決方案:

  • 如果連接埠被佔用，停止佔用的程式或修改 application.properties:
    server.port=8081

❌ 問題 2: API 返回 500 Internal Server Error

檢查步驟:

# 查看詳細錯誤訊息
curl.exe -v http://localhost:8080/api/orders

常見原因:

  1. 資料庫連線失敗
  2. JSON 格式錯誤
  3. 必填欄位缺失

解決方案:

  • 檢查應用程式日誌中的 Stack Trace
  • 確認 JSON 格式正確
  • 參考 問題處理.md

❌ 問題 3: Docker 服務無法啟動

檢查步驟:

# 檢查 Docker Desktop 狀態
docker version

# 查看容器狀態
docker-compose ps

# 查看容器日誌
docker-compose logs redis
docker-compose logs kafka

解決方案:

  1. 確認 Docker Desktop 正在運行
  2. 重啟 Docker 服務:
    docker-compose down
docker-compose up -d

❌ 問題 4: Kafka 連線錯誤 (不影響功能)

現象:

Connection to node -1 (localhost/127.0.0.1:29092) could not be established

說明:

  • 這是正常的，如果沒有啟動 Kafka
  • 程式已加入容錯處理，不會影響訂單建立

解決方案 (可選):

# 啟動 Kafka
docker-compose up -d kafka zookeeper

📝 測試腳本範例

完整測試腳本 (test-all.ps1)

# 測試腳本 - 完整 CRUD 操作

Write-Host "=== 訂單管理系統測試 ===" -ForegroundColor Green

# 1. 測試 GET (應該是空的)
Write-Host "`n1. 查詢所有訂單 (初始狀態)" -ForegroundColor Yellow
$orders = Invoke-RestMethod -Uri "http://localhost:8080/api/orders"
Write-Host "訂單數量: $($orders.Count)"

# 2. 測試 POST (建立訂單)
Write-Host "`n2. 建立新訂單" -ForegroundColor Yellow
$newOrder = @{
    customerName = "測試客戶"
    productName = "測試商品"
    quantity = 1
    price = 999
} | ConvertTo-Json

$created = Invoke-RestMethod -Method POST `
    -Uri "http://localhost:8080/api/orders" `
    -ContentType "application/json" `
    -Body $newOrder

Write-Host "訂單已建立，ID: $($created.id)"

# 3. 測試 GET by ID
Write-Host "`n3. 查詢單一訂單" -ForegroundColor Yellow
$order = Invoke-RestMethod -Uri "http://localhost:8080/api/orders/$($created.id)"
Write-Host "客戶: $($order.customerName)"
Write-Host "商品: $($order.productName)"
Write-Host "狀態: $($order.status)"

# 4. 測試 PUT (更新訂單)
Write-Host "`n4. 更新訂單" -ForegroundColor Yellow
$updateData = @{
    customerName = "測試客戶 (已更新)"
    productName = "測試商品 (已更新)"
    quantity = 2
    price = 1998
} | ConvertTo-Json

$updated = Invoke-RestMethod -Method PUT `
    -Uri "http://localhost:8080/api/orders/$($created.id)" `
    -ContentType "application/json" `
    -Body $updateData

Write-Host "訂單已更新"
Write-Host "新數量: $($updated.quantity)"
Write-Host "新價格: $($updated.price)"

# 5. 測試 GET (確認更新)
Write-Host "`n5. 再次查詢所有訂單" -ForegroundColor Yellow
$allOrders = Invoke-RestMethod -Uri "http://localhost:8080/api/orders"
Write-Host "訂單數量: $($allOrders.Count)"

# 6. 測試 DELETE
Write-Host "`n6. 刪除訂單" -ForegroundColor Yellow
Invoke-RestMethod -Method DELETE -Uri "http://localhost:8080/api/orders/$($created.id)"
Write-Host "訂單已刪除"

# 7. 測試 GET (確認刪除)
Write-Host "`n7. 最終查詢" -ForegroundColor Yellow
$finalOrders = Invoke-RestMethod -Uri "http://localhost:8080/api/orders"
Write-Host "訂單數量: $($finalOrders.Count)"

Write-Host "`n=== 測試完成 ===" -ForegroundColor Green

執行測試:

.\test-all.ps1
