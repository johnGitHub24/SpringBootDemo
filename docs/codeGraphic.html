Order CRUD — 四層骨架

  • OrderController → OrderService → JPA → H2。
  • REST /api/orders 標準 CRUD。
  • 無 Security（示範用排除 SecurityAutoConfiguration）。
  • Vue 3 ESM 前端 frontend/ 呼叫 API。
flowchart LR V[Vue frontend] --> OC[OrderController] OC --> OS[OrderService] OS --> OR[OrderRepository] OR --> H2[(H2 mem)]

Port 8080；驗證 .\gradlew.bat check。

Library — 第二模組示範

  • BookController 獨立 Library 路由。
  • 展示多 Controller 共存同一 Spring Boot。
  • 同樣 Controller → Service → Repository 分層。
  • 教學用模組邊界，非微服務拆分。
flowchart TB subgraph orders ["/api/orders"] OC[OrderController] end subgraph library ["/library"] BC[BookController] end OC --> OS[OrderService] BC --> BS[BookService] OS --> DB[(H2)] BS --> DB

詳見 使用手冊.md Library 章節。

進階 — Kafka / TCC / WebSocket

  • compose.yaml：Redis + Kafka + Zookeeper 可選。
  • advanced.*：SimulatedOrder／TCC 示範。
  • WebSocket PaymentNotificationController。
  • Java 21 語法示範 Java21FeaturesDemo。
flowchart LR APP[Spring Boot] --> K[Kafka optional] APP --> R[Redis optional] APP --> WS[WebSocket notify] APP --> TCC[TCC demo]

進階模組不影響 Order CRUD 主線 check 綠燈。
