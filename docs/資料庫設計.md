# SpringBootDemo 資料庫設計

> 衝突以 [SpringBootDemo-SPEC.md](../SpringBootDemo-SPEC.md) 為準。  
> 規範：EngineeringOS `knowledge/database-design.md`

## 1. 存取鏈

```text
Controller → Service (@Transactional) → Repository → H2
```

## 2. 資料表

| 表 | 用途 | 重要約束 |
|----|------|----------|
| `orders` | 訂單主檔 | PK `id`；`product_name`／`quantity`／`price`／`status` NOT NULL |
| `order_items` | 訂單明細 | FK → `orders`（`OrderItem.order`，cascade／orphanRemoval） |

狀態枚舉（`OrderStatus`）：含 `PENDING` 等（見 `com.demo.model.OrderStatus`）。

附屬示範：`Book`（library 模組）另有圖書表，非主契約。

## 3. Entity 對照

| Entity | 表 |
|--------|-----|
| `com.demo.model.Order` | `orders` |
| `com.demo.model.OrderItem` | `order_items`（mappedBy `order`） |

## 4. 環境

| Profile | DB | 設定位置 |
|---------|-----|----------|
| 預設／本機 | H2 mem `testdb` | `src/main/resources/application.properties` |
| 帳密 | sa／password | 同上；H2 Console path `/h2-console` |

`spring.jpa.hibernate.ddl-auto=update`；`defer-datasource-initialization=true`。

## 5. SQL 驗證

1. `.\gradlew.bat bootRun`
2. 開啟 H2 Console，JDBC URL：`jdbc:h2:mem:testdb`
3. 建議確認：

```sql
SHOW COLUMNS FROM ORDERS;
SHOW COLUMNS FROM ORDER_ITEMS;
SELECT o.id, o.customer_name, COUNT(oi.id) AS item_count
FROM ORDERS o
LEFT JOIN ORDER_ITEMS oi ON o.id = oi.order_id
GROUP BY o.id, o.customer_name;
```
