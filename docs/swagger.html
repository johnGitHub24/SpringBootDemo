SpringBootDemo — API 文件

Order CRUD · Library 示範 · 進階 Kafka／TCC 等 · Spring Boot 3.2 · Java 21 · H2 · Security 已排除（示範用）

CodeGraphic architecture.md 使用手冊 Runtime Swagger UI（:8080）

啟動與位址

啟動.\gradlew.bat bootRun（Redis／Kafka 可選：docker compose up -d）
Port8080
OpenAPI JSONhttp://localhost:8080/v3/api-docs（springdoc 新加入）
Swagger UIhttp://localhost:8080/swagger-ui.html
H2 Consolehttp://localhost:8080/h2-console（JDBC jdbc:h2:mem:testdb，帳號 sa，密碼 password）
驗證.\gradlew.bat check

API 分組（實際 Controller）

  • Orders：GET/POST /api/orders、GET/PUT/DELETE /api/orders/{id}
  • Library：GET /library/info、GET/POST /library/books、GET/PUT/DELETE /library/books/{id}、POST /{id}/borrow、POST /{id}/return
  • Test／示範：GET /api/test/reset、/java21、/kafka/verify、/tcc/workflow、/gateway/status、/calculator/add
  • 另有教學端點：/api/examples/*、/api/ms/*（模擬微服務）、/api/test-push（WebSocket 推播）。

認證與範例流程

  • 無認證：SecurityAutoConfiguration 已排除（示範用），啟動後可直接呼叫。
  • 範例：POST /api/orders 建單 → GET /api/orders 列表 → GET /api/test/kafka/verify／/tcc/workflow 走進階示範（需 Kafka 時先起 compose）。
  • 靜態規格對照：springbootdemo-api.yaml（手寫 OpenAPI，可與 live 文件比對）。

本頁載入 http://localhost:8080/v3/api-docs，請先啟動應用。若以 file:// 直接開啟本頁而無法載入， 請改用 http://localhost:8080/swagger-ui.html，或在 docs 目錄啟一個靜態伺服器（例如 python -m http.server）。
