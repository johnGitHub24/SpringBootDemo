# Claude AI 寫作核心指南

本指南旨在幫助您掌握使用 Claude AI 進行高效、高質量寫作的技巧。Claude 以其強大的邏輯推理與自然的語言風格著稱，非常適合用於撰寫文章、報告、代碼註解及創意內容。

---

## 1. 核心提示詞 (Prompting) 策略

### 賦予明確的角色 (Role Prompting)
與其直接說「幫我寫封信」，不如賦予 Claude 一個專業身份：
> **範例：** 「你是一位擁有 10 年經驗的技術資深文案，請幫我將這份技術說明轉化為易懂的部落格文章。」

### 提供寫作範本 (Few-shot Prompting)
如果您有特定的風格要求，請提供範例：
> **範例：** 「以下是我過去寫作的風格範例：[範例內容]。請仿照這種語氣撰寫關於 [主題] 的內容。」

### 使用 XML 標籤組織輸入
Claude 對於 XML 標籤（如 `<context>`、`<task>`、`<constraints>`）的解析非常敏銳：
```xml
<context>
  這是一篇關於 Java 21 特性的介紹。
</context>
<task>
  撰寫一段 200 字的主角介紹。
</task>
<constraints>
  語氣要專業但親切，不可使用簡體字。
</constraints>
```

---

## 2. 迭代寫作技巧

### 遞進式細化
不要期待一次生成完美長文。建議分階段進行：
1. **大綱階段：** 請求 Claude 建立結構化大綱。
2. **段落擴充：** 針對每個章節分別進行撰寫。
3. **優化潤飾：** 最後要求 Claude 進行風格統一與錯字檢查。

### 反饋與調整
如果 Claude 的輸出不符合預期，請具體指出問題：
- 「這段太過囉唆，請簡化。」
- 「請增加更多的具體技術實例。」
- 「語氣請更幽默一點。」

## 3. 實用寫作範本範例

### 代碼註解生成器
> 「請分析以下代碼，並使用 JavaDoc 格式撰寫繁體中文註解。重點說明參數、回傳值以及可能的異常處理。」

### 技術文章翻譯與在地化
> 「請將這篇英文技術文檔翻譯為繁體中文，並將術語在地化（例如：將 Array 翻譯為『陣列』，而非『數組』）。」

---

## 4. Claude 的優點與限制
- **優點：** 具有極強的連貫性、適合長文章處理、對複雜指令的遵循度高。
- **建議：** 對於非常敏感的事實性數據（如最新新聞），仍需要手動排查，因為 Claude 的知識截點可能有限。
