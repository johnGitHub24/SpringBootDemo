# Vue.js 前端介面使用手冊

我們已經為「訂單管理系統」建立了一個現代化且漂亮的 Vue.js 前端介面。這份文件將告訴你如何執行它。

---

## 1. 如何啟動前端網頁

由於我們使用的是 CDN 方式引用 Vue 3 與 Tailwind CSS，你不需要安裝 `node` 或 `npm`，只需簡單的三個步驟：

1.  **啟動後端**：確保你的 Spring Boot 專案已經成功啟動（Port 8080）。
2.  **定位檔案**：在檔案總管中找到 `frontend/index.html`。
3.  **直接開啟**：對著該檔案連點兩下，或拖曳到瀏覽器（Chrome, Edge 等）中開啟即可。

## 2. 功能介紹

這個介面具備了完整的 CRUD（除了修改以外的查詢、新增、刪除）功能：
*   **讀取列表**：網頁載入時會自動從後端抓取所有訂單，並美觀地顯示出來。
*   **新增訂單**：透過表單輸入客戶名稱、產品、數量與價格，點擊按鈕即可即時新增。
*   **重新整理**：如果你手動改了資料庫，點擊右側的「重新整理」按鈕即可同步。
*   **刪除功能**：點擊卡片右邊的垃圾桶圖示即可刪除對應訂單。

## 3. 初學者學習點

如果你是第一次接觸前端框架，可以從這兩個檔案學到：

### 在 `index.html` 中：
*   **Tailwind CSS**：你可以看到我們使用 `bg-indigo-600` 這樣的標籤來設定顏色，而不需要寫傳統的 CSS。
*   **v-model**：這是 Vue 最強大的功能之一，讓輸入框的東西與程式內部的資料連結。
*   **v-for**：就像程式碼的 `for` 迴圈，用來將一堆訂單數據轉成一整排的漂亮卡片。

### 在 `app.js` 中：
*   **Axios**：這是業界最常用的非同步通訊工具，讓你可以在不刷新網頁的情況下與後端 Java 進行溝通。
*   **async / await**：這是處理「需要等待的事物」（如資料傳輸）的最現代化寫法。

---

> [!TIP]
> **遇到問題了嗎？**
> 如果打開網頁看不到資料，請檢查瀏覽器按 `F12` 打開「開發者工具」並查看 `Console` 標籤。
> *   若是 404：請確認後端是否已啟動。
> *   若是 CORS 錯誤：請確認 `com.demo.config.WebConfig` 是否已正確建立。
